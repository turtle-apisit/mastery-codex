# Miller's Law and Stepwise Refinement

## Summary

**Miller's Law:**

> *"At any one time, we can concentrate on only approximately **seven chunks**
> (units of information)."*

This is a hard limit on human working memory, and it is the reason the technique
below exists.

**Stepwise refinement** is used to handle larger amounts of information than
seven chunks:

- **Concentrate on the aspects that are currently the most important**
- **Postpone** aspects that are currently **less critical**
- **Every aspect is eventually handled**, but **in order of current importance**
- **This is an incremental process**

Stated as a design principle in Class 4:

> *"Postpone decisions as to details as late as possible, to be able to
> concentrate on the important issues."*

## Key points

- Stepwise refinement is called **a basic principle underlying many software
  engineering techniques** — it is not one technique among many, it is a
  foundation.
- It is the bridge from a fact about human cognition (Miller's Law) to a fact
  about process (incrementation). That link is the exam-worthy part.
- The class illustrates it with a **drawing** video — the artist blocks the whole
  composition roughly first, then refines. The whole picture exists at every
  stage; only the detail level changes.

## Watch out for

- "Postpone the details" is not "skip the details". Every aspect **is eventually
  handled** — the technique reorders work, it does not drop it.

## Prerequisites

None — this is a root concept for the subject.
